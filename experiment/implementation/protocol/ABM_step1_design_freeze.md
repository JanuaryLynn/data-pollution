# 第一步成果：研究方案与分析口径确定

版本：design-v1.0；日期：2026-09-22。

**本文件固定本轮重跑前的研究问题、模型边界、参数、主要比较和统计规则，作为下一步改代码的依据。**  `ABM_step1_protocol.json` 主要服务于程序读取，方便阅读和新一轮修改时的复习。


## 1. 研究问题和本轮边界

研究对象是**社交网络中污染状态的传播与治理**。比较治理的覆盖、频率、判断能力及靶向方式如何影响抑制效果与误伤暴露。法律与平台使用共同的账号选择和二元判断结构；制度差异只能在已经建模的维度上解释。

本轮修改后的实验采用以下边界：

- 固定网络、无外生污染输入、无自发恢复；无治理时是 SI 型，治理净化后可再感染，属于 SIS-like 动态。
- 误伤记录为治理代价，不删除节点、断开连边、改变传播参数或取消后续审核资格；不新增申诉、退出或误伤反馈机制。
- P3 仅让平台审核人数随真实污染规模变化。候选仍是全网，不模拟举报识别或筛查器。
- P3、P5、P6 分别检验，不追加三者的全交叉，也不把 BA 上的补充结果外推为已验证全部网络。
- 参数是情境化设定，tick 没有固定的现实日历含义；不增加训练数据回流、模型再训练或实证校准的完成声明。

注：P3等等这些标号是指导老师对上一版本论文的修改意见整理编号，主要服务于让作者本人回头看的时候能够看得懂，如果你看不懂，也没有关系，因为不重要。

## 2. H1–H3：先明确比较，再看结果

以下均在 p0=10%、30%、50% 三层分别分析，不先混合三个环境。主要效果指标为每次运行 step 1–50 的平均效果，再求运行间均值，记为 μE。所有效果与误伤差值使用百分点。

**透明性说明：** 这些假说和对比是在已查看上一版本的旧代码 v1.8 数据后、尚未运行本轮新版实验前明确的。属于有历史结果依据的假说澄清，并非未经数据启发的预测。

### H1：参数交互与高干预区域的收益压缩

保留“参数效果存在非线性和交互”的研究问题，将具体预测限定为：在高频或高覆盖、接近效果上限的区域，进一步提高另一参数带来的收益趋于压缩。**不再预测法律覆盖收益在 τ=10→5→1 全过程中逐档递减。**

法律的覆盖增益定义为：

\[
D_L(\tau)=\mu_E(L=90,\tau)-\mu_E(L=50,\tau),
\qquad \mathrm{TPR}=\mathrm{TNR}=95\%.
\]

平台的准确率增益定义为：

\[
D_A(c)=\mu_E(\alpha=90,c)-\mu_E(\alpha=70,c),
\quad c=n_p,\quad \mathrm{TPR}=\mathrm{TNR}=\alpha.
\]

| 预设比较 | 每个 p0 的对比 | 预期方向及解释 |
|---|---|---|
| 法律高频相对中频 | D_L(1)−D_L(5) | 负值：最高频率下覆盖增益较小 |
| 法律高频相对低频 | D_L(1)−D_L(10) | 负值：最高频率下覆盖增益较小 |
| 平台全覆盖相对低覆盖 | D_A(100)−D_A(50) | 负值：全覆盖下准确率增益较小 |
| 平台全覆盖相对中覆盖 | D_A(100)−D_A(75) | 负值：全覆盖下准确率增益较小 |

共 4×3=12 个主要交互对比。完整网格用于解释响应形状；不根据图形事后挑一对差值替代上述比较。负向对比与收益压缩一致，但仅凭该对比不能证明具体“阈值”或饱和的唯一成因；需要同时展示响应水平与曲线。

### H2：指定治理参数空间内的容量敏感性

预测仍是：在规定范围与分布下，μE 对法律覆盖和干预间隔、平台覆盖的敏感性高于对各自对称准确率的敏感性。法律两个维度分别比较，不相加。

**本次固定 PAWN（10 个条件区间、区间 KS 距离的中位数）为主要重要性口径。** PRCC 用于方向及单调关系下的强弱说明；PAWN 的 5/20 区间及均值、最大值作为稳定性诊断。这样可以避免跑完后选择更有利的指标。PAWN 可基于同一输入输出样本计算，官方说明亦列出中位数等汇总方式。[方法说明](https://salib.readthedocs.io/en/latest/api/SALib.analyze.html#module-SALib.analyze.pawn)

每个 p0 报告三个主要指数差：PAWN(L)−PAWN(αL)、PAWN(τ)−PAWN(αL)、PAWN(np)−PAWN(αP)，合计 9 个。正值与预测一致；区间跨零或设置变化导致排名不稳时，报告无法清楚区分。只在部分分层成立时，结论相应收窄。PRCC 与 PAWN 不一致时解释二者刻画的关系，不更换主要口径。

H2 的主要响应是 μE；O(50) 按老师要求同样计算敏感性，用于解释代价来源。不能用“准确率对 O 更重要”替代对 H2 的判断，也不能将本设计的排名解释为每增加一个百分点或每花相同成本的政策收益。

### H3：实现效果的不同路径及其误伤代价

预测是：扩大干预范围或提高频率可能同时提高效果与误伤暴露；提高判断能力可能改变这一权衡。两个结果必须一起报告，不依据 E 单独排名主体，也不预设任何补充机制必然“双赢”。

| 路径 | 固定的高水平减低水平比较 | 其他设置 |
|---|---|---|
| 法律覆盖 | L=90%−50% | τ=5，TPR=TNR=95% |
| 法律频率 | τ=1−10 | L=70%，TPR=TNR=95% |
| 平台覆盖 | np=100%−50% | 固定审核量，TPR=TNR=80% |
| 法律判断能力 | αL=100%−90% | L=70%，τ=5，TPR=TNR=αL |
| 平台判断能力 | αP=90%−70% | 固定审核量，np=75%，TPR=TNR=αP |

共 5×3=15 组比较，每组联合报告 ΔμE 与 ΔO(50)。前三项预计可能出现“效果增加、误伤也增加”；后两项检验改善判断能力能否缓解权衡。不要求所有分层同时出现相同象限；若效果或误伤差异不清楚，直接报告不确定性。

净效果 E−λO 为补充指标，λ=1 是规范性设定，不据此声称得到客观最优治理方案。

## 4. 固定的模型执行规则

1. 每次运行重新生成网络，单次运行不改变连边。BA 沿用 NW 优先连接生成器 m=2；ER 连边概率 2m/(N−1)；WS 沿用手写环形近邻及重连算法，每侧 m 个邻居，重连概率 0.1。平均度近似对齐，不筛除孤立点或不连通网络。
2. 所有非负人数换算统一为 floor(x+0.5)，并限制到 0…N；在 Python 与模型中使用一致规则。p0=0、super-ratio=0、审核覆盖=0 均允许产生零个节点，不强行至少取 1。
3. 超级传播者按度数选一次，边界并列随机处理后身份固定；初始污染随机抽取。每轮审核重新按 degree-targeted 或随机无放回选择，度数并列沿用随机处理，不按节点编号固定打破并列。
4. 每个 tick：清零本步计数 → 传播 → 现场统计审核前污染人数 → 到期治理 → 更新状态与累计指标 → 记录该步。传播时使用本步开始时的污染传播者集合；本步新感染者从下一步开始传播。
5. 法律在记录 step=1、1+τ、… 时治理；τ 是相邻行动的间隔，不是首次等待期。50 步内行动机会数为 1+floor(49/τ)。另记录实际有审核的步数与审核人数，不混淆“行动机会”和“非零工作量”。
6. 平台 fixed 每步审核 min{N,round(N×np/100)}；state-responsive 审核 min{N,round(N×np/100),round(κ×Npoll_pre)}。Npoll_pre 必须在传播后、治理前现场计算。
7. 每个被审核账号产生 TP、FN、TN、FP 之一。TP 将污染置为干净，FP 只更新误伤事件及独立误伤标记。审核人数=TP+FN+TN+FP。同一节点可在不同步重复受审或产生事件。
8. 即使污染为零，也完成 50 步；固定审核仍可继续造成误伤，按需审核则为零。无行动步骤的本步计数全部为 0，累计值保留。
9. 网络诊断、导出及内部累计不得额外改变演化的随机数序列。完整轨迹和仅最终导出必须在同配置、同种子下给出相同状态及汇总；此项在小批核验中验证。

TNR 不直接影响传播状态是上述模型结构的含义；不能将其包装为现实中错误处置没有传播后果的经验发现。TPR 改变净化与后续干净账号受审暴露，因此也可能改变 O。

## 6. 指标、区间和分析规则

| 字段 | 运行级定义与用途 |
|---|---|
| E_mean | (1/50)Σ E(t)，t=1…50；主要效果指标 |
| O_final | 100×截至step50至少一次在干净状态受误伤的独立节点数/N；主要代价指标 |
| E_final | E(50)；辅助，解释法律终点相位 |
| PR_final | 100×累计TP/(累计TP+累计FP)；分母为0记NA |
| net_E_mean / net_E_final | E−λO 的时间均值和最终值；辅助 |
| reviews、TP/FP/TN/FN | 每步及累计事件；干净审核暴露=TN+FP |
| network diagnostics | 边数、实际平均度、度标准差、最大度、孤立点及超级传播者结构 |

E、O、PR 全部用 0–100 尺度。先计算每次运行指标，再汇总 30 次；不把 tick 当独立重复。PR 取各次有效比例的均值，不用跨运行合并 TP/FP 的比率替代，并报告 n_valid。零分母不填零。

条件均值报告 n、均值、SD、SE、95% Student t 区间。对比采用独立运行条件均值的线性对比；同一条件被引用多次，先合并权重 w，再计算方差 Σ w²s²/n，使用 Welch–Satterthwaite 自由度。共享基准的多个对比保留协方差；若联合重抽，每个条件每轮只抽一次，E 与 O 成对抽取同一次运行。

本轮主要呈现效应量与逐项 95% 区间，不使用显著性星号，不将逐项区间解释成全体比较同时具有 95% 保证。不因一个区间跨零就声称两配置等效，不因个别对比方向一致就宣称整个 H1–H3 得到证实。零样本方差如实报告，不解释为现实不确定性为零。

百分数区间保留原始上下限；展示可另行限制到0–100并注明。图2轨迹区间为逐时点区间，不称为整条曲线的同时置信带。

补充比较预先固定：P3 按需减 fixed，逐 κ/p0 比较 E、O、PR 与工作量；P5 targeted 减 random，逐主体/覆盖/p0 比较 E/O；P6 展示全部 TPR×TNR 响应，并在固定另一准确率时比较最高减最低水平。拓扑使用 ER−BA、WS−BA；规模使用5000−1000。各自始终保持其他设置一致。

### P4 的具体统计设置

- 每个主体/p0 的分析输入为 500 行完整参数及各点 30 次运行的 E_mean/O_final 均值；不把 15,000 次随机重复当15,000个独立设计点。
- PAWN 主分析将每个输入分为 10 个等频区间；连续输入用完整设计的经验分位边界，边界值只归一个箱且包含最大值；τ按1–2、3–4、…、19–20分组。5/20区间分别作诊断；不把同一整数τ拆组。
- 每箱对响应均值分布与全部500点响应均值分布计算 KS 距离，取中位数。保存箱计数及各箱距离；该指数无效应方向，也不是解释方差百分比。
- PRCC 使用平均秩处理并列，控制同主体其余输入；结合响应图检查单调性。非单调时低PRCC不能解释成无影响。
- 1,000次完整设计行 bootstrap，同时重算全部输入指数及其差，报告2.5%–97.5%近似区间；固定原设计的分组边界。另做1,000次固定设计点、点内运行重抽，仅诊断模拟噪声，不把两种区间相加。E/O共同抽取运行，行重抽保留整行关系。
- 分层重抽种子分开记录：法律三个p0的行重抽为750101–750103，点内重抽为751101–751103；平台分别750201–750203、751201–751203。比较20次与30次重复的指数和排名。
- 普通行bootstrap不保留完整LHS分层结构，区间是近似稳定性描述，不声称严格设计型覆盖保证。记录有效重抽次数；常量响应、秩残差为零或空分组返回诊断，不输出可解释的排名。
- 不根据是否支持H2决定补跑。若模拟噪声或设计点覆盖不足，记录具体诊断、追加方式和新版设计；本阶段不虚构充分性阈值。现有网格不追加进LHS样本改变其分布。

## 7. 运行身份、输出和后续执行

配置编号在下一步由统一生成器按本文件模块顺序分配、完整配置去重后固定；每配置重复编号1–30。种子为：

```text
seed = 20260922 + 1000 * condition_id + replicate_id
```
